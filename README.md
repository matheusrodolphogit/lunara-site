# lunara-site
Landing Page para Agência de Automação Imobiliária.

Tipo: Projeto pessoal

Desenvolvi a Lunara, uma landing page institucional para uma agência fictícia especializada em soluções de inteligência artificial, automação de processos e integração de sistemas voltadas ao mercado imobiliário.
O projeto apresenta uma identidade visual moderna e dinâmica, com foco na organização das informações, clareza na apresentação dos serviços e experiência de navegação.
Durante o desenvolvimento, trabalhei na estruturação da página, criação dos elementos visuais e implementação de recursos interativos, buscando construir uma interface funcional e alinhada à proposta da agência.
A proposta também contempla uma estratégia de apresentação comercial, utilizando a landing page como ferramenta para estabelecer contato com empresas do setor imobiliário e agendar reuniões para apresentar as soluções desenvolvidas pela agência. Essa abordagem permitiu explorar não apenas os aspectos técnicos do projeto, mas também sua aplicação prática em um contexto de negócio.
Também implementei, utilizando JavaScript, uma funcionalidade para registrar os cliques no botão de contato via WhatsApp, permitindo acompanhar as interações dos visitantes com a página.

Linguagens utilizadas

HTML: estruturação e organização do conteúdo.

CSS: estilização, identidade visual e construção do layout.

JavaScript: implementação de funcionalidades interativas e registro de cliques no botão de WhatsApp.
